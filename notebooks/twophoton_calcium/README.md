This folder contains demos for how to run the two-photon pipeline on different kinds of commonly acquired datasets. Includes

- Axonal/Dendritic imaging
- Population somatic imaging (this covers a wide set of use cases)

This type of imaging is most commonly performed with a resonant galvo system, but these pipelines work identically on newer ultrafast point scanning imaging methods: 
(1) FACED imaging
(2) Light Beads microscopy
